서버가 피해와 도착점을 판정합니다.

0.5.0은 두 인증 플레이어의 기본 공격·HP, 상호작용 포털과 독립 게임 폴더 CLI를 제공합니다. 기존 이동·GUID·에셋 경로를 사용합니다.

프로젝트에서 공격 규칙을 정하세요.

.myeproj에 onlineCombat을 추가하고 File → Input Settings에서 사용자 액션 attack의 키를 지정합니다. 첫 누름에 같은 맵의 가장 가까운 상대에게 요청하며 서버가 거리·층·벽·HP·쿨다운을 검사합니다.

"onlineCombat": { "range": 1.5, "power": 1.0, "cooldownTicks": 30 }

필드가 없으면 공격은 꺼집니다. range는 월드 unit, cooldownTicks는 60Hz 틱입니다. 사망은 이동/공격을 막고 재접속으로 회복하지 않습니다. 부활과 타격 모션 연결은 다음 작업입니다.

문과 고유 도착점을 연결하세요.

  1. 문에 ScenePortal과 활성 InteractionTarget을 추가합니다.
  2. onInteract=true, 목적지 scenePath와 도착 오브젝트의 고유 ObjectName을 spawnName으로 저장합니다.
  3. 도착점의 FloorLevel을 목적지 플레이어와 맞추고 충돌 밖에 둡니다. E를 누르면 준비·검증·전환 순으로 진행합니다.

같은 서버 세션의 HP·성장·가방은 유지됩니다. 다른 맵의 플레이어는 복제하지 않고 이전 epoch의 입력을 거부합니다. 현재 마지막 저장 맵 재접속은 MyGame --scene assets/scenes/other.scene으로 명시합니다.

저장한 게임을 새 폴더에 내보내세요.

MyEditor.exe --project "D:/Game/project.myeproj" --export-game "D:/Games/MyGame" --runtime "D:/MyEngine-0.5.0-windows-x64"

같은 버전 Release 런타임·폰트·고지와 assets/.meta를 복사하고 Play.cmd를 만듭니다. 출력은 기존 부모 아래의 새 폴더여야 합니다. 저장하지 않은 초안은 포함하지 않습니다. 원본 없이 다른 위치에서 실행해 확인하세요. export 메뉴·설치 프로그램·서버 배포는 아직 없습니다.

기본 연결과 MMO 완성을 구분하세요.

온라인은 loopback 개발 전송이며 클라이언트 Lua를 실행하지 않습니다. NPC·스킬·드롭/퀘스트·보상·온라인 HUD/채팅·표현용 VFX·자동 마지막 맵 discovery·공개 인터넷 운영은 다음 작업입니다. 로컬 Lua 테이블의 맵/저장 상태 전달도 별도입니다.

서버 데이터를 먼저 백업하세요. 0.5.0은 예전 저장을 읽고 version 2/records로 저장합니다. 구버전 서버는 새 형식을 거부하므로 다운그레이드에 같은 데이터를 재사용하지 마세요.
