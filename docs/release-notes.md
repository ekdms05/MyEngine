# MyEngine 0.2.2

- MeshRenderer·BillboardRenderer를 두 공식 앱의 공통 씬 등록·저장·로딩 경로에 연결했습니다.
- 정적 GLB/임베디드 glTF 임포트와 메시 GUID 해석을 연결하고, 손상된 accessor/index를 거부합니다. 메시의 정면 컬링과 빈 알베도 표시를 수정했습니다.
- 빌보드의 Full/YAxis/None·발 피벗·반전과 기존 SpriteAnimator 모션 경로를 연결했습니다.
- 저장 가능한 Camera3D를 추가했습니다. 위치·target·FOV·near/far·이름 추종 오프셋을 Play/MyGame에서 사용합니다. Play 복원 직후 파생 좌표도 검증합니다.
- 요소 추가 창에서 메시·빌보드·게임 카메라를 만들고 Inspector/Undo/저장으로 편집할 수 있습니다.
- 기본 에디터 글꼴을 나눔스퀘어라운드 Regular로 변경하고 OFL·내장 보완 폰트 고지를 배포합니다.
- 개발 MCP의 명시적 외부 프로젝트 루트와 원본 범위를 지원합니다. 절대 입력·루트/junction 탈출·기존 에셋 덮어쓰기 방지는 유지합니다.

3D 선택/기즈모·XYZ 물리/Lua·온라인 MyGame·게임 HUD 제작·게임/서버 내보내기는 아직 제공하지 않습니다. 메시의 glTF 노드 변환·재질·리깅·외부 .bin 자동 연결도 지원하지 않습니다. 이 버전은 3D 표시/카메라 경로 개선이며 온라인 3D MMORPG 제작 완료를 의미하지 않습니다.

## 기존 편집·제작 기능

- 프로젝트 생성·불러오기 창에서 시작하고, 프로젝트를 선택한 뒤 에디터를 엽니다.
- 작업대를 2D·3D·Lua로 정리하고 요소 추가·인스펙터의 간격과 사용 설명을 보완했습니다.
- 실행 시 별도 게임 창을 엽니다. 일시정지·재개·중지는 동일한 PlayWorld를 제어합니다.
- 에셋 브라우저의 우클릭 가져오기·폴더 생성·휴지통 이동을 지원합니다. 에셋 식별자는 기존 `.meta` GUID를 사용합니다.
- Sol2를 제거하고 Lua 5.4 C API로 직접 연결했습니다. Lua 함수·콜백·제약을 제작 가이드에 정리했습니다.
- 도트 제작·리깅은 외부 제작 도구에서 수행하고 PNG·`.anim`을 가져오는 흐름으로 정리했습니다. 오래된 데모와 초기 연구 자료는 배포에서 제외했습니다.
- MCP에 프로젝트 검사·API 참조·에셋 가져오기를 연결했습니다.
- Windows 배포 빌드는 CMake가 설치된 Visual Studio를 선택합니다. 존재하지 않는 Visual Studio 2022를 강제하던 설정을 제거했습니다.
- 같은 에셋 폴더를 다른 경로 표기로 감시할 때 변경된 파일을 찾지 못하던 문제를 수정했습니다.

Windows x64, DirectX 11 환경용입니다. [최신 Microsoft Visual C++ v14 x64 런타임](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)이 필요합니다. ZIP을 새 폴더에 풀고 `MyEditor.exe`를 실행하세요. 기존 프로젝트는 새 버전에서 열기 전에 백업을 권장합니다.

에디터의 게임 창은 같은 프로세스의 별도 창입니다. 프로세스 장애 격리, 게임 내 UI 시각 편집, 자동 완성·중단점 디버깅, 온라인 클라이언트 통합은 제공하지 않습니다. Lua VM·ImGui·실제 사용 중인 디코더와 글꼴 라이브러리는 유지합니다.
