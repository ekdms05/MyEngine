# 초원마을 기본 프로젝트

MyEditor의 첫 프로젝트와 새 프로젝트의 기본 에셋 선택에 사용하는 콘텐츠다. 캐릭터와 배경은 독립된 씬 엔티티다.

| 에셋 | 용도 | 원본 크기 / 동작 |
|---|---|---|
| `assets/environment/meadow_village.png` | 초원·세 집·우물·개울·다리 배경 | 1672×941 RGB, 화면 960×540에 맞춘 배율 |
| `assets/characters/novice.png` | 초보 모험가 시트 | 2170×725 RGBA, 8개 프레임 영역 |
| `assets/animations/novice_idle.anim` | 대기 애니메이션 | 프레임 0–3, 각 0.30초, 반복 |
| `assets/animations/novice_walk.anim` | 걷기 애니메이션 | 프레임 4–7, 각 0.14초, 반복, footstep 이벤트 |
| `assets/scenes/meadow_village.scene` | 시작 씬 | 배경 1개, 레벨 1 캐릭터 1개 |

캐릭터는 `Progression.level=1`, `xp=0`이다. 초기 위치는 `(0, -0.9, 0)`, 렌더 배율은 `0.15`, 기본 애니메이션은 대기다. 레벨 값은 Inspector에서 확인할 수 있다. 파일을 저장해 재실행하거나 PlayWorld로 복제해도 유지된다.

에셋 창의 `animations/`에서 `.anim`을 더블 클릭하면 프레임·시간·피벗·이벤트를 편집할 수 있다. 캐릭터를 선택한 뒤 **선택한 스프라이트에 지정**으로 대기·걷기 클립을 바꾸고 씬을 저장한다. Play에서는 애니메이션이 재생되며, 대기·걷기 전환을 입력 이동에 연결한 게임 컨트롤러는 포함하지 않는다.

새 클립은 PNG를 패널의 시트 영역에 놓고 셀 크기를 지정해 만든다. 제공된 시트는 균등 격자가 아닌 프레임별 영역·발밑 피벗을 `.anim`에 기록했다. 원본 PNG를 자르거나 리샘플링하지 않는다. 이미지의 집·나무는 배경에 합쳐져 있으므로 개별 건물 이동, 지형 타일 편집, 다리 층·충돌·내비게이션은 아직 제공하지 않는다. 해당 제작 계약을 마련할 때 별도 지형·오브젝트 에셋으로 분리한다.

PNG와 `.meta`는 함께 이동해야 GUID 참조가 유지된다. 원본 기본 프로젝트 대신 새 프로젝트로 복사한 콘텐츠를 편집한다. 첫 실행은 사용자 프로젝트 폴더로 한 번 복사하며, 다시 실행할 때 기존 프로젝트와 수정한 파일을 유지한다.

이 기본 아트에는 타사 게임·캐릭터·로고·외부 에셋 팩을 사용하지 않았다. 제작 도구·프롬프트와 검증 근거는 저장소 `docs/16-foundation-worklog.md`에 기록한다. 외부 팩의 라이선스를 적용하거나 출처를 타사 작업으로 표시하지 않는다.
